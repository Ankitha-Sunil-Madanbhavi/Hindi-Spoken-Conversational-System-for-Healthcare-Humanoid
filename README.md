# Hindi-Spoken-Conversational-System-for-Healthcare-Humanoid
Introduction
Engineering solutions in the healthcare sector improved the healthcare systems significantly. There are numerous examples of it, from X-ray to Magnetic Resonance Imaging (MRI), laser surgery to stem cell cultivation, etc. Lately, robotic surgery and robots in the healthcare sector have increased significantly. Human-like robots or humanoids are being developed for various domains such as healthcare, military, and retail shops. Human-Robot interaction is the essential want in humanoids. Since speech is humans' most preferred mode of communication, and likewise, vision and navigation are the standard expectation in a humanoid, these features are embedded in it. Recently, there have been numerous companies doing research and development on humanoids and deploying them for various applications.

A Spoken Conversational System is an application that enables human-like conversational interaction with computers, i.e. Humans can communicate with computers in the form of speech or text. Generally, a spoken conversational system has three main components, viz. 1. Automatic Speech Recognition (ASR), 2. Natural Language Processing (NLP), 3. Text to Speech Synthesizer (TTS). The ASR does the job of converting the spoken speech signal into corresponding text. In NLP, the language understanding part understands the input text and identifies the intent of the input sentence. Subsequently, the language generation part replies back with appropriate reply. TTS converts the text into a speech. When these three are in pipeline, it acts as the Spoken Conversational system. Recently there have been more significant improvements in these particular areas because of the boom in machine learning algorithms.

A robot looking like a human having the interaction features like humans do, and at the same time having the ability to navigate autonomously is a futuristic system that anyone wants to have in his/her home. Building such a system or a robot is a complex task as it involves building many components such as mapping the environment, object detection, navigation, rerouting, face detection and recognition, speech recognition, language understanding, Text-To-Speech systems. Building such components and integrating them to work synchronously in real-time is a challenging task. In this work we attempt to build a speech based conversational system in Hindi using which people can interact with the humanoid in real-time.

The rest paper proceeds as follows. In the second section, the literature review explains the existing similar systems found in the literature. The third section explains a framework for the human-robot interaction. The fourth section explains about the implementations carried out in this regard. Section five concludes the paper and also informs about the possible future works.
